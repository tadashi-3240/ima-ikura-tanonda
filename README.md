# 今いくら頼んだ？

注文するたび、合計がわかる。

焼肉・居酒屋・中華などで、今いくら頼んだかをすぐ確認できる、お客さん側専用の注文金額メモです。店員向けの POS や売上管理ではありません。

食事中にスマートフォンを片手で操作し、注文を数秒で追加できることを最優先にしています。

## 起動方法

```powershell
cd C:\Users\User\Desktop\ima-ikura-tanonda
npm install
npm run dev
```

ブラウザで表示されたローカル URL（通常は `http://localhost:5173`）を開きます。

音声入力を使う場合は、`localhost` または HTTPS で開いてください。

## Expo Go で実機確認

協豊モバイル伝票と同じく、**LAN ではなくトンネル**で接続します。

```powershell
cd C:\Users\User\Desktop\ima-ikura-tanonda\mobile
npm install
npm start
```

Expo Go で、表示された `exp://....exp.direct` の QR コードを読み取ってください。LAN の `exp://192.168.x.x` は使いません。

Expo Go では、画面下の入力欄に「ビール650円を2つ」のように入れて追加してください。

## ビルド方法

```powershell
npm run build
npm run preview
```

`npm run preview` で本番ビルドを確認できます。PWA（ホーム画面追加・オフライン）の確認はビルド後の preview が確実です。

## テスト方法

```powershell
npm test
```

自動テストでは次を確認します。

1. `1750 × 2 = 3500`
2. `600 × 2 = 1200`
3. 数量省略時は 1
4. 「650円を2つ」を 650 + 2 と解釈しない
5. 「650円を2つ」は 650 × 2
6. 「1100円×2」の解析
7. 「600円二つ」の解析
8. 同じ商品の追加で数量合算
9. 数量変更で合計更新
10. サンプルデータの総額 14,550円
11. localStorage からの復元

## PWA としてホーム画面に追加する方法

GitHub Pages に公開したあと、iPhone の **Safari** で公開 URL を開きます。

1. 共有ボタンをタップ
2. 「ホーム画面に追加」を選ぶ
3. 名前が「今いくら頼んだ？」になっていることを確認して追加

公開 URL は次です。

https://tadashi-3240.github.io/ima-ikura-tanonda/

### Android（Chrome）

1. メニュー（⋮）を開く
2. 「アプリをインストール」または「ホーム画面に追加」を選ぶ

オフラインでも、注文の入力・計算・localStorage への保存は動作します。

## 対応している音声入力

Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`）が使えるブラウザで、マイクボタンから日本語音声入力できます。

- 対応の目安: Chrome / Edge（Android・PC）、Safari（iOS は端末・設定による）
- 言語: `ja-JP`
- 流れ: マイク → 話す → 文字起こし → 確認カード → 「追加する」
- 使えない環境では、画面下の文字入力と手入力フォームだけで同じことができます

飲食店名・料理名の誤認識に備え、音声入力後は確認カードを出します。「追加する」を大きく、「修正」は小さくしています。

## 主な機能

- 現在の合計を大きく表示
- 「ローストホース1750円を2つ」のような自然文から商品名・単価・数量を解析
- 数量の省略時は 1、`2つ` / `二つ` / `×2` / `2個` などに対応
- 音声入力（対応ブラウザのみ）
- 手入力（商品名 / 単価 / 数量。数量の初期値は 1）
- 注文一覧（スマートフォンはカード、広い画面は表）
- 数量の＋−、同じ商品の合算、編集・削除
- 任意の予算（残り / オーバー表示）
- 新しい会計（確認つきで注文を消去）
- localStorage 保存（商品・単価・数量・予算）
- 直前操作の Undo（追加・削除・数量変更・金額変更）
- ダークモード（店内でも読める配色を既定）

割り勘、人数別計算、POS、レジ、売上・在庫・席・店舗・会員管理は実装していません。
